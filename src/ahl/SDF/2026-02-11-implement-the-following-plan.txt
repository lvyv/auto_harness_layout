│ 1.1 PathConstraint 数据类                                                    │
│ @dataclass                                                                   │
│ class PathConstraint:                                                        │
│     reference_path: np.ndarray  # (N, 2) 已布线路径                          │

│ 1.2 compute_path_distance_field(path, sdf_grid) → (ny, nx)                   │

│ - 对路径的每对相邻顶点计算线段距离场，取 element-wise 最小值                 │
│ - 返回网格上每个点到折线路径的最短距离                                       │

│ 1.3 build_cost_modifier(constraints, sdf_grid) → (ny, nx)（A* 用）           │
│ - 对每个约束计算影响因子：influence = clip(1 - dist/radius, 0, 1)            │
│ - 吸引：modifier *= max(1 - strength * influence, 0.05) → 路径附近代价降低   │
│ - 排斥：modifier *= (1 + strength * influence) → 路径附近代价升高            │
│ - 多个约束的 modifier 累乘                                                   │
│                                                                              │
│ 1.4 build_speed_modifier(constraints, sdf_grid) → (ny, nx)（FMM 用）         │
│ - 吸引：modifier *= (1 + strength * influence) → 路径附近速度提高            │
│ - 排斥：modifier *= max(1 - strength * influence, 0.05) → 路径附近速度降低   │
│                                                                              │
│ 1.5 nearest_point_on_path(points, reference_path) → (nearest_points,         │
│ distances)                                                                   │
│ - 对每个查询点，在参考路径折线上找最近点及距离                               │
│ - 复用 sdf_line_segment                                                      │
│ 中的投影逻辑（primitives.py:45-49），但额外返回最近点坐标                    │
│ - 供梯度优化器计算梯度方向                                                   │
│                                                                              │
│ 1.6 path_constraint_cost_and_gradient(path, constraints) → (cost, grad)      │
│ - 供 GradientOptimizer 使用，接口风格与 gradient.py:54                       │
│ _obstacle_cost_and_gradient 一致                                             │
│ - 吸引代价：C(p) = 0.5 * s * (d/r)²，梯度指向远离参考路径方向 →              │
│ 梯度下降时路径靠近参考                                                       │
│   - grad += s * d / r² * unit_outward                                        │
│ - 排斥代价：C(p) = 0.5 * s * ((r-d)/r)²，梯度指向靠近参考路径方向 →          │
│ 梯度下降时路径远离参考                                                       │
│   - grad -= s * (r-d) / r² * unit_outward                                    │
│ - 仅对 dist < influence_radius 的点生效                                      │
