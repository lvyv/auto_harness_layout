● 问题根因在两处：参数导致速度场退化 + 梯度回溯缺少障碍物检查。

  ---
  问题 1：safety_margin=0 导致除零，速度场变成阶跃函数

  _sdf_to_speed 第 44 行：

  normalized = np.clip(sdf_grid.values / self.safety_margin, 0.0, 1.0)
  #                                       ^^^^^^^^^^^^^^^^^ = 0 → 除零!

  当 safety_margin=0 时：
  - sdf > 0 → +inf → clip 到 1.0
  - sdf = 0 → nan → clip 保持 nan
  - sdf < 0 → -inf → clip 到 0.0

  问题 2：speed_exponent=0 使所有值变成 1

  第 45 行 speed = normalized ** 0：
  - 1.0 ** 0 = 1.0
  - nan ** 0 = 1.0（numpy 约定）
  - 0.0 ** 0 = 1.0

  把障碍物内部设为极小值。

● 问题找到了。

  根因分析

  A* 的 启发函数不可容许（inadmissible） 导致吸引约束完全失效。

  启发函数（第 86 行）：
  h(n) = 欧氏距离 × spacing        ← 假设每格代价 = 1.0

  但 cost_modifier 吸引模式下，走廊内的单格代价被降到了 0.05：
  走廊内: cost_grid = base_cost × 0.05 = 0.05
  走廊外: cost_grid = base_cost × 1.0  = 1.0

  此时 h(n) 对走廊内路径的预估是实际代价的 20 倍，严重高估。

  A* 的 f 值 = g(已走代价) + h(估计剩余)：
  ┌──────────┬─────────────┬─────────────────┬───────────┐
  │ 节点位置 │  g (累计)   │    h (估计)     │ f = g + h │
  ├──────────┼─────────────┼─────────────────┼───────────┤
  │ 走廊入口 │ 0.05 (很低) │ 8.0 (按1.0估的) │ 8.05      │
  ├──────────┼─────────────┼─────────────────┼───────────┤
  │ 直行一步 │ 1.0 (正常)  │ 7.0 (降了1.0)   │ 8.0       │
  └──────────┴─────────────┴─────────────────┴───────────┘
  走廊节点的 f 值反而更高！A*
  永远优先展开直行节点，走廊被完全忽略。在某些几何条件下甚至找到比 baseline
  更差的路径（因为不可容许启发函数不保证最优性）。

  修复

  启发函数必须乘以代价场的最小值，保证 h(n) ≤ 实际剩余代价：

● 修复完成。总结一下这个 bug：

  问题

  原启发函数 h(n) = 欧氏距离 × spacing 隐含假设：每格最低代价 = 1.0。

  当 cost_modifier 的吸引模式把走廊代价降到 0.05 时，h(n)
  对走廊路径的估计是真实代价的 20 倍，严重违反 A 的可容许性条件*（h(n) ≤ 
  h*(n)）。

  后果：
  - 走廊节点的 f = g + h 被人为抬高，A* 始终优先展开走廊外的节点
  - 走廊的低代价优势被高估的 h 完全淹没
  - A* 退化为非最优搜索，找到的路径忽略甚至回避走廊

  修复

  min_cost = cost_grid 中有限值的最小值   # attract 时约 0.05
  h(n) = 欧氏距离 × spacing × min_cost   # 保证 ≤ 真实剩余代价

  修复后 f 值对比：
  ┌──────────┬──────┬───────────────────┬──────┐
  │ 节点位置 │  g   │    h (修复后)     │  f   │
  ├──────────┼──────┼───────────────────┼──────┤
  │ 走廊入口 │ 0.05 │ 8.0 × 0.05 = 0.4  │ 0.45 │
  ├──────────┼──────┼───────────────────┼──────┤
  │ 直行一步 │ 1.0  │ 7.0 × 0.05 = 0.35 │ 1.35 │
  └──────────┴──────┴───────────────────┴──────┘
  走廊节点的 f 值大幅低于直行节点 → A* 正确探索走廊 → 吸引生效。

  副作用：min_cost 越小启发函数越弱，A*
  探索的节点更多（速度稍慢）。但这是正确性和完备性的必要代价。无 cost_modifier 
  时 min_cost = 1.0，行为不变，完全向后兼容。
